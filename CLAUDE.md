# Bot Creator — правила для агентов

## Scope-контракт: у каждой сущности бота объявлен тип

Разбор и обоснование — `docs/SCOPE_AUDIT_STAGE_A.md`.

Каждая сущность бота обязана быть явно отнесена к одному из двух типов.
Сущность без объявленного типа считается **ошибкой генерации**, а не
недоработкой оформления.

- **SCOPED** — записи принадлежат родительской записи. Список без указания
  родителя бессмыслен: операции ДДС по туру, гости мероприятия, задачи
  проекта, сдачи по заданию.
- **GLOBAL** — записи ни к чему не привязаны и осмысленны общим списком:
  прайс-лист, справочник категорий, штат, журнал заказов.

Внешний ключ типа не определяет. Родитель **содержит** записи или только
**описывает** их? «Все расходы за месяц» — осмысленный запрос, поэтому
расходы GLOBAL, а `category_id` работает фильтром. «Все операции ДДС»
вперемешку по всем турам — бессмыслица, поэтому они SCOPED.

### Для SCOPED обязательны

1. колонка `parent_id` (или иная колонка родителя) с индексом;
2. фильтрация по родителю во всех выборках-списках;
3. имя родителя в заголовке списка и в карточке — имя, не id;
4. агрегаты по текущей выборке, а не по всей таблице;
5. запрос родителя при создании: молча создать сироту нельзя.

Пункт 5 требует внимания: проверка «ключ присутствует в payload» пропускает
пустую строку. Проверять надо непустоту — именно этот пробел породил
операции ДДС, не видимые потом ни в одном туре.

### Машиночитаемое объявление

В `miniapp_config` каждый ресурс несёт `scope`:

```python
"scope": {"type": "scoped", "parent": "tours", "via": "tour_id"}
"scope": {"type": "global"}
```

`parent` — имя другого ресурса в этом же конфиге, у него должен быть
`titleField`. `via` — колонка на таблице самого ресурса, объявленная среди
его `fields`.

Ресурс без `scope` валит сборку: `python -m scripts.check_miniapp_drift`.
Проверка проверена на намеренно сломанных примерах —
`tests/test_miniapp_drift.py::ScopeCheckActuallyFailsOnBrokenInput`.

### Обратная ошибка

Не пытайся показать родителя у GLOBAL-сущности. В движке мини-аппа это
невозможно конструктивно: `resource_scope()` схлопывает и `global`, и
отсутствие объявления в `None`, а весь код про родителя живёт внутри
`if scope is not None`. В логике шаблонов такой защиты нет — там следи сам.
Показанный «тур» у справочника отелей — реально допущенная ошибка.

## Прочее

- Кнопки вместо текстовых команд везде, где возможно. Эталон —
  `templates/moderator.py`.
- В репозитории часто работают параллельные сессии в разных worktree.
  Перед мержем сверяйся с актуальным master фактами (`git log`,
  `git status`), а не по памяти.
