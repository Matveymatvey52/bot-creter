Реестр ботов — переработка

Макет новой структуры перед тем, как начинать код. Горизонтальные вкладки вместо текущих 7 плиток, drill-down в бота / пользователя / отзыв, Telegram-идентичность видна everywhere.

Важно перед реализацией: вкладка «Отзывы» ниже требует нового хранилища — сейчас в БД по каждому боту хранится только avg_rating и feedback_count (агрегат), а кто именно поставил оценку и что написал в комментарии — не сохраняется отдельной записью нигде. Чтобы кликать на конкретный отзыв и видеть автора + писать ему в Telegram, нужно завести таблицу отдельных отзывов (rater_telegram_id, rating, comment, created_at) — это бэкенд-работа, не только фронт. Также для фото/имени владельцев сейчас в реестре есть только «владелец #» (голый Telegram ID) — понадобится подтягивать профиль через Telegram Login данные, которые уже приходят при авторизации.

01 · Общая навигация

Реестр (владелец залогинен через Telegram Login Widget — фото+имя видны в шапке) │ ├─ 🤖 Боты → список всех запущенных ботов → карточка бота ├─ 👤 Пользователи → список владельцев ботов → его боты → карточка бота ├─ ⭐ Отзывы → список оценок → карточка отзыва ├─ 📊 Обзор → total / active / paused ├─ 🧩 Шаблоны → боты по шаблону ├─ ⚙️ Фичи → адопция фич по ботам └─ ✏️ Правки → суммарно правок / незакрытые паттерны Свайп влево/вправо переключает вкладки. Один и тот же тап на бота из ЛЮБОЙ вкладки открывает одну и ту же карточку бота (уровень 2).
Вкладки 4–7 (Обзор / Шаблоны / Фичи / Правки) — предположение по составу текущих 7 плиток. Нужно подтвердить у владельца, что группировка верна, при реализации.

Открытые вопросы для владельца

Вопрос 1
Состав вкладок 4–7 — «Обзор / Шаблоны / Фичи / Правки» — моё предположение по текущим 7 плиткам реестра. Верно?
Вопрос 2
Вкладка «Отзывы» требует новой таблицы отзывов (сейчас хранится только агрегат) — ок начинать с этого как с отдельного бэкенд-этапа перед фронтом?
Вопрос 3
Кнопка «Написать» на отзыве/пользователе — это диплинк в Telegram (открывает чат в самом Telegram-приложении), а не чат внутри мини-аппа. Подходит?
Это вайрфрейм — цвета/шрифты ориентировочные, важна структура и flow. После «да» перехожу к реализации: сначала таблица отзывов на бэкенде, потом сама вёрстка вкладок.
